# CineCam Tools 1.0: test record

Every checklist from plumbing to step 4.3, as Tim ran them in the editor (UE 5.8.3, workbench project). Kept as the record of what 1.0 was checked against. Unticked items were skipped, with the reason on the line.

New work gets its own checklist file (for example `1.1.md`).
